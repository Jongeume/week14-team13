## Day 1 - 2026-11-27 — Forward

### 오늘 직접 구현한 것

- `Affine.forward`
    
    - 역전파에서 사용할 입력값 `x` 저장
    - 행렬 곱셈을 통한 가중합 계산
    - 브로드캐스팅을 통한 편향 덧셈

- `ReLU.forward`
    
    - 0 이하인 원소의 위치를 Boolean Mask로 저장
    - 원본 입력 배열 복사
    - Boolean Indexing을 통한 비활성화 위치의 값 변경
    - 활성화 결과 반환


### 오늘 확인한 shape와 수식

**입력/출력 shape**

우리 신경망 구조: 784 → 128 → 10

|구분|Shape|
|---|---|
|입력 데이터 X|(N, 784)|
|W1|(784, 128)|
|b1|(128,)|
|Affine1 출력|(N, 128)|
|ReLU 출력|(N, 128)|
|W2|(128, 10)|
|b2|(10,)|
|Affine2 출력(Logits)|(N, 10)|

- N은 배치 크기이며, 한 번에 처리하는 이미지의 개수이다.
- 배치 크기가 변경되어도 가중치와 편향의 Shape는 변경되지 않는다.
- Shape는 배열의 각 축의 크기를 나타낸다.

**손으로 확인할 계산**

Affine 연산식: XW + b

테스트 코드의 `make_layer()` 기준 예상 결과

```
- x = [[1, 2], [3, 4]]
- W = [[1, 2, 3], [4, 5, 6]]
- b = [1, 0, -1]
- 가중합 = [[9, 12, 15], [19, 26, 33]]
- 편향 적용 결과 = [[10, 12, 14], [20, 26, 32]]
```
- 최종 출력 Shape: (2, 3)

브로드캐스팅은 편향 벡터를 가상으로 확장하여 각 입력 데이터의 가중합에 동일한 편향을 더한다.

**반드시 성립해야 하는 조건**

- 입력 배열의 마지막 축 크기와 가중치 행렬의 첫 번째 축 크기가 같아야 한다.
- 편향의 원소 개수는 해당 계층의 뉴런 개수와 같아야 한다.
- Affine 연산 전후 배치 크기는 동일해야 한다.
- ReLU 연산 전후 Shape는 동일해야 한다.
- ReLU는 원본 입력 배열을 변경하지 않아야 한다.
- ReLU는 0 이하의 값을 0으로 변경하고 양수는 유지해야 한다.
- Affine의 x와 ReLU의 mask는 역전파를 위해 저장되어야 한다.


### 막힌 지점과 해결 과정

**1. Affine의 행렬 곱셈 구현**

- 증상: 교재에서는 `np.dot()`을 사용하지만 구현 요구사항에서는 `@` 연산자를 사용하여 혼란이 생겼다.
- 내가 세운 가설: 입력값과 가중치의 행렬 곱셈 이후 편향을 더하면 된다.
- 시도 1: `np.dot()`과 `@`의 역할 비교
- 시도 2: `return x @ self.w + self.b` 작성
- 해결: 2차원 배열의 행렬 곱셈에서는 두 연산의 결과가 동일하며, Python은 대소문자를 구분하므로 `self.W`를 사용해야 한다.


**2. ReLU의 Boolean Mask 구현**

- 증상: 0 이하인 원소의 위치를 어떻게 저장해야 하는지 몰랐다.
- 내가 세운 가설: if 조건문으로 0 이하인 값을 판별하면 될 것이다.
- 시도 1: `if x <= 0:` 사용
- 시도 2: NumPy 배열의 원소별 비교 연산 학습
- 해결: `self.mask = (x <= 0)`을 통해 조건을 만족하는 위치를 Boolean 배열로 저장할 수 있다.


**3. ReLU의 배열 복사 및 값 변경**

- 증상: 원본 배열을 유지하면서 특정 위치의 값만 변경하는 문법을 몰랐다.
- 시도 1: `out = x.copy()` 작성
- 시도 2: 복사와 값 변경, 반환을 한 줄로 처리하려고 시도
- 해결: `x.copy()`로 배열을 복사하고, `out[self.mask] = 0`으로 특정 위치의 값을 변경한 뒤 반환한다.


**4. ReLU의 비활성화와 Shape**

- 증상: 은닉층 뉴런 128개 중 30개가 비활성화되면 출력 데이터가 98개라고 생각했다.
- 내가 세운 가설: 비활성화된 뉴런은 다음 계층으로 전달되지 않는다.
- 해결: ReLU는 뉴런을 제거하는 것이 아니라 출력값을 0으로 변경하는 함수이다. 따라서 활성화 여부와 관계없이 Shape는 유지된다.

### 코드 없이 답할 질문 3개

1. Affine 계층에서 행렬 곱셈과 브로드캐스팅은 각각 어떤 역할을 하며, 배치 크기에 따라 Shape는 어떻게 변화하는가?

	답: Affine 계층은 행렬 곱셈을 통해 각 뉴런의 가중합을 계산하고, 브로드캐스팅을 통해 배치 내 모든 데이터에 동일한 편향 벡터를 더한다.
	 
	배치 크기가 변경되면 **입력과 출력의 첫번째 축만 변경**되며, 가중치와 편향의 **shape는 유지**된다.


2. 신경망에서 ReLU를 사용하는 이유는 무엇이며, 뉴런이 비활성화되어도 Shape가 유지되는 이유는 무엇인가?

	 답: 신경망에서 ReLU를 사용하는 이유는 **비선형성을 부여하여 선형 분리만으로 해결할 수 없는 문제를 학습하기 위해서이다.**
	
	**Affine 연산만 반복**하면 결국 **하나의 Affine 연산으로 표현**할 수 있기 때문에 신경망의 표현 능력이 제한된다. ReLU를 적용하면 비선형성을 확보할 수 있으며, **0을 제외한 모든 지점**에서 **미분 가능**하므로 **역전파를 통한 기울기 기반 학습**에도 활용할 수 있다.
	
	또한 ReLU는 0 이하인 뉴런의 출력값을 0으로 변경하고 양수인 출력값은 그대로 전달한다. **뉴런이나 배열의 원소를 제거하는 것이 아니라** **값만 변경하기** 때문에 입력과 출력의 Shape는 동일하게 유지된다.


| 특성       | 의미 및 목적                  |
| -------- | ------------------------ |
| 비선형성     | 선형 분리로 해결할 수 없는 문제를 학습   |
| 연속성      | 모든 지점에서 함수의 값이 끊어지지 않음   |
| 미분 가능성   | 기울기를 계산하여 역전파에 활용 (=변화량) |
| 비활성화     | 0 이하인 뉴런의 출력값을 0으로 변경    |
| Shape 유지 | 원소를 제거하지 않고 값만 변경        |


3. Affine과 ReLU는 순전파에서 각각 어떤 데이터를 저장하며, 왜 저장해야 하는가?

	Affine과 ReLU는 **역전파에서 기울기를 계산하고 전달하기 위해 순전파 당시의 정보를 저장한다.**
	
	**Affine**은 **가중치에 대한 손실의 기울기를 계산**하기 위해 **입력값 `x`를 저장**한다.
	
	**ReLU**는 순전파에서 **비활성화된 위치**를 `mask`에 저장하고, **역전파에서 해당 위치의 기울기를 0으로 처리하여 차단**하며 **활성화된 위치의 기울기는 그대로 전달**한다.
	
	두 계층 모두 상태 저장이 순전파의 출력값 자체에 영향을 주지는 않지만, 이후 역전파를 수행하기 위해 필요하다.
